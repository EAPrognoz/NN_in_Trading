## English

This repository contains the source code for the article series “Neural Networks in Trading”. It includes implementations in MQL5 and OpenCL, usage examples, and auxiliary scripts for reproducing experiments with neural network components in the MetaTrader 5 environment.
The main objective of the project is to demonstrate the practical integration of neural network modules into trading Expert Advisors and to provide a reproducible foundation for research and development of algorithmic trading systems.

## Русский

Этот репозиторий содержит код к серии статей «Нейросети в трейдинге». Здесь собраны реализации на MQL5 и OpenCL, примеры использования и вспомогательные скрипты для воспроизведения экспериментов с нейросетевыми компонентами в среде MetaTrader 5.
Основная цель проекта — показать практическую интеграцию нейросетевых модулей в торговые советники и предоставить воспроизводимую основу для исследований и разработки алгоритмических торговых систем.

## Українська

Цей репозиторій містить код до серії статей «Нейромережі в трейдингу». Тут зібрані реалізації на MQL5 та OpenCL, приклади використання й допоміжні скрипти для відтворення експериментів із нейромережевими компонентами в середовищі MetaTrader 5.
Головна мета проєкту — продемонструвати практичну інтеграцію нейромережевих модулів у торгові радники та надати відтворювану основу для досліджень і розробки алгоритмічних торгових систем.
