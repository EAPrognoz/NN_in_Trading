# AlphaQCM r8

AlphaQCM использует формульную грамматику, финансовую среду и торговый PPO AlphaGen. Поиск и обучение Q/IQN выполняются на OpenCL GPU. Профиль IQN-QCM-v1 задан в Trajectory.mqh.

Соберите Study, StudyOnline и Test через MetaEditor MCP в каталоге MQL5, содержащем Experts и стандартные Include. Для каждого советника требуется 0 ошибок и 0 предупреждений. Для исполнения необходим MT5 с доступным OpenCL GPU.

Условия приёмки AQCM-TASK-r8 §6.1 — EURUSD H1, MetaQuotes-Demo, серверное время котировок. Для StudyOnline и Test в Strategy Tester выберите M1 OHLC, депозит 1000 USD и плечо 1:100. Начало периода включено, конец исключён.

| Сценарий | Пресет | Период | Работа с checkpoint |
|---|---|---|---|
| Study | Presets/01Study.set | 2024-01-01 → 2024-04-01 | Начать с отсутствующего файла модели. Штатное завершение сохраняет r8-A.nn. |
| Продолжение Study | Presets/02StudyContinue.set | 2024-04-01 → 2024-07-01 | Скопировать A под именем r8-B.nn. После нового принятого обновления нажать Stop and save. |
| StudyOnline | Presets/03StudyOnline.set | 2024-07-01 → 2026-01-01 | Скопировать B под именем r8-C.nn. Сохранить итоговую C и отчёт Tester. |
| Test | Presets/04Test.set | 2026-01-01 → 2026-11-01 | Загрузить r8-C.nn и сохранить торговый отчёт Tester. |

Модели находятся в Terminal/Common/Files/AlphaQCM. Для повторного обучения при наличии результатов приёмки укажите отдельные имена ModelFile и последовательно передавайте модели по цепочке A → B → C. Для проверки уже обученной модели используйте Test и неизменную C. Даты в пресетах Study записаны целыми секундами для входов datetime MetaTrader.

Study и StudyOnline сохраняют checkpoint через временный файл, проверочный Load и замену с резервной копией. На каждый ModelFile допускается один писатель.
