# AlphaQCM

AlphaQCM использует формульную грамматику, финансовую среду и торговый PPO AlphaGen. Поиск и обучение Q/IQN выполняются на OpenCL GPU.

Соберите Study, StudyOnline и Test через MetaEditor MCP в каталоге MQL5, содержащем Experts и стандартные Include. Для каждого EA требуется сборка с 0 ошибок и 0 предупреждений. Запускать на MT5 с доступным OpenCL GPU. Встроенные параметры IQN-QCM-v1 заданы в Trajectory.mqh. Число потоков и объём физической плитки зависят от устройства.

Для приёмки использовать EURUSD H1, MetaQuotes-Demo и серверное время котировок. В Strategy Tester для StudyOnline и Test выбрать M1 OHLC, депозит 1000 USD и плечо 1:100. Настройка M1 OHLC уточнена заказчиком 24.11.2026. Использовать отдельный чистый экземпляр/график, чтобы ручные операции и другие советники не меняли торговое состояние. Участки заданы в AQCM-TASK-r7, §6.1. Начало включено, конец исключён.

| Стадия | Пресет | Период | Результат |
|---|---|---|---|
| Study | Presets/01Study.set | 2024-01-01 → 2024-04-01 | Отсутствующий A.nn создаётся после штатного конца |
| Продолжение Study | Presets/02StudyContinue.set | 2024-04-01 → 2024-07-01 | Скопировать A.nn в B.nn перед пуском. После нового принятого update и дальнейшей работы нажать Stop and save |
| StudyOnline | Presets/03StudyOnline.set | 2024-07-01 → 2026-01-01 | Скопировать B.nn в C.nn перед пуском. Сохранить итог C.nn и отчёт Tester |
| Test | Presets/04Test.set | 2026-01-01 → 2026-11-01 | Загрузить фиксированный C.nn и сохранить торговый отчёт |

A.nn, B.nn и C.nn находятся в Terminal/Common/Files/AlphaQCM. Сохранение сначала пишет временный файл и проверяет его штатной загрузкой, затем обновляет резервную копию и заменяет основной файл. Выходной путь должен иметь одного писателя. После ошибки сохранения в Study можно повторить Save той же кнопкой.

Study использует доступную причинную предысторию. Для Test разрешён только rewarm сохранённого Active Pool на доступных закрытых барах. Для оценки фиксируйте реальный объём работ, обновления обеих сетей, синхронизацию targets, публикацию Active, торговые обновления, сделки и время проходов вместе с журналами и отчётами Tester.

Для повторной приёмки AQCM-TASK-r8 используйте пресеты в `Presets/r8`. Они
пишут `r8-A.nn`, `r8-B.nn` и `r8-C.nn` в том же каталоге моделей.
Перед продолжением Study скопируйте r8-A.nn под именем r8-B.nn. Перед
StudyOnline скопируйте r8-B.nn под именем r8-C.nn. Эти имена сохраняют
контрольные модели прошлой редакции. Формат дат в пресетах Study — целое
число секунд для входов datetime MetaTrader.
